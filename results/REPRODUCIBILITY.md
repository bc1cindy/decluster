# Reproducibility policy

Every claim in `results/` falls into one of four states. This is the single index; per-doc
"Reproducibility / provenance" footers point back here.

## The rule

A claim's **mechanism** (the algorithm) is proven by a unit test on small/synthetic input. A claim's
**headline number** is a different thing: most are population statistics or live-fetch runs over
data that is too large or non-representative to commit (`slice_2026.ndjson` 1.1 GB, `.cache/`,
`.blkcache/`). A small committed fixture reproduces a *different* number, so a headline population
statistic cannot be unit-asserted exactly — only where the claim is a **ratio / gap / separation that
survives subsampling** can it be pinned as a **band** on a committed fixture.

## 2. Mechanism unit-tested, headline number is a data-run (proven algorithm, labelled number)

The algorithm is pinned; the reported value is regenerated by an `examples/*.py` script over
unversioned data and is not asserted. This is a deliberate choice, not a gap — a brittle
subsampled fixture would assert a different number.

## 3. Reproducible once a small BigQuery window is committed

Run the query, commit the small output as a fixture, and the number becomes band-pinnable (state 1).

| Claim | Query | Notes |
|---|---|---|
| slice-gate spanning material | `bigquery/slice_gate.sql` | aggregate, few rows |
| persistence curve | `bigquery/persistence_curve.sql` | 5-row aggregate |
| change-id validation | `bigquery/slice.sql` | 1-day labelled slice |
| fingerprint frequency calibration | `bigquery/sample_small.sql` | already sized small |

## 4. Needs a new representative collection (no small fixture substitutes)

- **ancestry (ε,δ)-sparsity** — needs deep contiguous ancestry connectivity; a small window has ~1%
  in-file parents. The definitive run is a deep contiguous export at dss-oracle depth.
- **definitive reid** — the chain-wide de-anonymization *rate* (not the link, which is pinned in
  state 1) needs a uniform chain sample at real depth with the dss oracle, an API collection.
